🖨 Printer Thermal 58mm (TM58M)

Pilih metode cetak sesuai cara printer kamu terpasang.

Cash drawer harus tersambung ke port DK/kick drawer pada printer. Pengaturan ini hanya berlaku untuk cetak Bluetooth.

Catatan: Mode Bluetooth hanya berjalan di Chrome (Android/Desktop) karena pakai Web Bluetooth API — tidak didukung Safari/iPhone. Untuk iPhone, gunakan mode "Print biasa" dengan printer yang sudah terpasang lewat AirPrint/driver.
